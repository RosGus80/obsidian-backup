Проект должен представлять из себя удобный минималистичный трекер для управления проектом.
#### ЦА:
Фрилансеры, работающие над одним проектом удаленно
Фрилансеры, работающие над проектом в одиночку (в меньшей степени)
Клиенты, пользующиеся услугами фрилансеров

Приложение должно представлять из себя удобный менеджер для ведения проекта с возможностью распределять задачи на членов команды, вести учет за дедлайнами и прогрессом, вести учет над оплатой проекта, иметь возможность представлять наглядный отчет о прогрессе выполнения клиенту (автоматическое формирование отчета на основе текущих тасков).

При создании проекта можно выбрать иерархию: все равны или распределение ролей
Если в проекте есть менеджер (роль администратора), то он создает таски и прикрепляет их к членам команды или оставляет на дешборде, откуда таск может взять любой из участников команды. Тот, кто взял таск, далее отчитывается о прогрессе и обновляет его. 

При подходе к дедлайнам таски выделяются, а при горящих дедлайнах приходят уведомления. 

Также нужно вести простой учет за прикрепленными документами, относящимися к проекту. 

#### Головные боли, которые решаются:
Менеджмент за командой с отчетливыми тасками
Учет за оплатами 
Автоматические отчеты клиенту с наглядным прогрессом
Учет документов в одном месте


#### Дизайн:

Примерный флоу:

* На главном экране список проектов с их названиями, общей текущей стоимостью, контактами клиента.
* При создании проекта заполняются поля:
название
контакт клиента
дедлайн проекта (дедлайн сдачи и дедлайн оплаты)
Валюта проекта (по умолчанию стоит из преференций пользователя)

В окне можно пригласить участников в команду (нажимаешь плюс, вводишь имейл, нажимаешь галочку/ввод и приглашение будет отправлено юзеру с этим имейлом)
* На главном экране проекта находится дэшборд, доступный всем членами команды. На нем находятся текущие (невыполненные) задачи. Думаю, можно сделать графический обзор и табличный обзор (в графическом можно будет свободно двигать таски по дэшборду - сделать систему координат и все такое), все можно помечать разными уветами, в общем, чтобы понравилось белым женщинам
* При добавлении задачи: название задачи, подзадачи (также, как с приглашением: нажал плюс, ввел подзадачу, галочка, добавилась), есть ли за нее оплата (если нажимаешь галочку, открывается филд с бюджетом задачи), дедлайн задачи, работник (выбираешь члена команды и прикрепляешь ему задачу)
* Панель оплат будет висеть слева с полученными/будущими деньгами (250/500). Нажав на него, откроется список оплат, которые можно изменить или пометить проведенными. Также можно добавить новую оплату (она добавляется в общший бюджет), дедлайн оплаты, статус оплаты, файл (например, чек, если нужно)



#### Монетизация:
Первые х созданных проектов бесплатно с некоторым набором закрытых фич. Далее - по подписочной системе с несколькими уровнями подписки. На первом таки есть ограничение по кол-ву доступных одновременно проектов (например, 3) и членов команды (например, 5 не включая пользователя)
