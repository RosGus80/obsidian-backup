
To change the style of header and tabs, we have to use screenOptions prop of Tabs field.

```
<Tabs
screenOptions={{
tabBarActiveTintColor: '#e28743',
headerStyle: {
	backgroundColor: '#25292e',
},
headerShadowVisible: false,
headerTintColor: '#fff',
tabBarStyle: {
	backgroundColor: '#25292e',
}
}}>...</Tabs>
```
