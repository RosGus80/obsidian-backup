
### Подключение к серверу

Подключение к серверу такое же, как обычно: по ssh-ключам.

На локальном компьютере надо сгенерировать ssh-ключ и прожать все поля, не заполняя их:
`ssh-keygen`
Скопировать ключ на удаленный сервер:
`ssh-copy-id root@[ip]`
Ввести пароль для пользователя root

Безпарольный доступ по ssh-ключу подключен.

Теперь надо установить на сервер необходимое ПО. Установить стоит python3-pip и, если понадобится, nginx:
`sudo apt update`
`sudo apt install python3-pip` или `sudo apt install python3-venv`

### Перенос проекта на сервер

Надо создать репозиторий с проектом на гитхабе/гитлабе/где удобно.
После этого привязать там (на гитхабе/гитлабе/...) новый ssh-ключ к своему аккаунту. 
Для этого на удаленном сервере сделаем `ssh-keygen` и скопируем ключ по печатаемому пути в значение поля ключа для нашего нового ключа.
Далее стоит перейти в `/usr/local/bin` и скопировать туда проект из репозитория:
`git clone [url] [proj_name]`

Далее надо создать виртуальное окружение проекта и скачать туда необходимые пакеты:
`python3 -m venv env`
`source env/bin/activate`
`pip3 install -r requirements.txt`

Потом заполнить .service файл:

![[Запуск бесконечного приложения на сервере#Заполнение .serivce файла]]

Чтобы использовался интерпретатор пайтон из нашего виртуального окружения, стоит прописать такое значение для ExecStart:
Если наш проект называется tgbot:
`ExecStart=/usr/local/bin/tgbot/venv/bin/python3 /usr/local/bin/tgbot/main.py`
Такие большие абсолютные пути можно не писать, используя
`WorkingDirectory=/usr/local/bin/tgbot`
`ExecStart=/venv/bin/python3 main.py`
Суть от этого остается прежней

Далее можно запустить сервис, бот выгружен и работает

![[Запуск бесконечного приложения на сервере#Чтобы запустить сервис вручную,]]


Чтобы посмотреть логи для нашего сервиса, можно использовать команду:
`journalctl -u tgbot.service`
