
1) Количество элементарных операций (для больших входных данных)
2) Задействование памяти

Элементарная операция - простейшее обозначенное в машинном языке действие, совершаемое вычислительной машиной, то есть такое действие, которое не может быть представлено совокупностью более простых

Примеры:
<; >; >=; <=; ==; =...

Для оценки количества операций, проводимых алгоритмом, можно представить его в виде математической функции, где аргументом будет размер входных данных, и тогда значение функции будет равно количеству операций, требуемых для его исчисления (так, чем быстрее растет значение функции, тем медленнее будет исполняться наш алгоритм)

Из-за этого существуют классы сложности, потому что классы функций ведут себя схоже в вопросе скорости своего роста (потому что производные так исчисляются). Например, линейная сложность, квадратичная сложность, логарифмическая сложность, корневая сложность и т.д.

Это и есть нотация большого О (пишется О и в аргументе - класс функции - $O(N^2)$)
