Дефлятор

$P_{t}= \frac{nY_{t}}{Y_{t}}$ (t - год, Y - ВВП, n - "номинальный")


Задача 1
Млн ден ед	   Базовый.     Отчетный
ВЫпуск.          402,3            790,3
Налог              28,1                57,4
СУбсидии.      7,3                  7,5
Промежут потреб 239        489,2
Изм цен. на выпуск %       81,9
Изм цен на потребление.  % 91
Индекс налогооблагаемой продукции 1,196

Производств ВВП = выпуск - промежут потреб + налог - субсид


Дефлятор = ном ВВП (отчет)/реальн ВВП(отчет)

Реальн ВВП = ном ВВП (отчет)/рост цен

Ном/реальн ВВП (баз) = 402,3 + 28,1 - 7,3 - 239 = 184,1
Ном ВВП (отчет) = 790,3 + 57,4 - 7,5 - 489,2 = 351
реальн ВВП = 181,9%

Двойн дефлят = 

$489,2 = 1,91 * x$
$x = 489,2/1,91 \approx 256,13$

$790,3 = 1,819 * x$
$x = 790,3/1,819 \approx 434,47$

20,8*1,196 = 24,9

Реальн ВВП = 434,47 - 256,13 + 24,9 = 203,24

Дефлят = $\frac{351}{203,24} \approx 1,727$
