
Логика высказываний рассматривает утверждения как атомарные частицы, которые однозначно истинны или ложны и фокусируется на связях между такими высказываниями. Логика предикатов рассматривает высказывания как состоящие из переменных, значение которых влияет на истинностное значение выражений. 

Эквивалентные функции - такие, значение которых равно при любых значениях аргументов
Противоречия - функции, всегда принимающие ложное значение
Тавтологии - функции, всегда принимающие истинное значение

Конъюнктивная нормальная форма - конъюнкция нескольких простых дизъюнкций
Дизъюнктивная нормальная форма - дизъюнкция нескольких простых конъюнкций

Для любой булевой функции существует эквивалентная ей КНФ и ДНФ

Построение ДНФ и КНФ:
ДНФ: Для булевой функции находим строку, в которой она равна 1. выписываем эту строку: $(x_{1}, x_{2}, \dots x_{n}) = (0, 1 \dots 1)$. Для каждой единицы запишем переменную $x_{k}$, а для каждого нуля - $\lnot x_{k}$ и свяжем их конъюнкцией. Получится запись $\lnot x_{1} \land x_{2} \dots \land x_{n}$, которая будет всегда принимать значение, равное значению оригинальной функции на этом значении переменных. 
КНФ: Для булевой функции находим строку, в которой она равна 0. Выписываем эту строку: $(x_{1}, x_{2}, \dots x_{n}) = (0, 1 \dots 1)$. Для каждого нуля запишем переменную $x_{k}$, а для каждой единицы запишем $\lnot x_{k}$. Свяжем их дизъюнкцией и получим запись $x_{1} \lor \lnot x_{2} \dots \lor \lnot x_{n}$

Далее нам достаточно проделать это для каждой строки и связать их соответствующим образом (дизъюнкциями - для днф, конъюнкциями - для кнф)

Если функция противоречива, то ДНФ равна $\lor \emptyset$ (пустая дизъюнкция всегда равна нулю)
Если функция тавтологична, то КНФ равна $\land \emptyset$ (пустая конъюнкция всегда равна единице)
