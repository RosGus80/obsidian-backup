
1) Сложение векторов:
	   $\vec{a} + \vec{b} = \vec{c}$ если $ci = ai + bi$ (складывать можно только векторас равным кол-вом элементов)
2) Умножение вектора на скаляр:
	   $k*\vec{a} = \vec{b}$ если $bi = ai*k$
3) Скалярное произведение векторов:
	Если кол-ва элементов $\vec{a}$ и $\vec{b}$ равны и равны n, то их скалярное произведение равно $\sum_{i=i}^{n}a_{i}*b_{i} = a_{1}*b_{1} + a_{2}*b_{2} + ... + a_{n}*b_{n}$
4) Длина вектора
	Длина вектора = $|a| = \sqrt{ A*A } = \sqrt{ a_{1}^2 + a_{2}^2 + ... + a_{n}^2}$
	Если $|a| = 1$, вектор называется **единичным**

### Свойства операций над векторами:

1) Коммутативности сложения
	A + B = B + A
2) Ассоциативности сложения
	(A + B) + C = A + (B + C)
3) Дистрибутивности умножения на скаляр
	k(A + B) = kA + kB
4) $\vec{0} + A = A$
5) Коммутативности скалярного умножения
	A * B = B * A
6) Дистрибутивности скалярного умножения
	A * (B + C) = A * C + B * C
7) Ассоциативности скларяного умножения умножению на число
	k * (A * B) = k * A * B
8) Если $|A| = 0$, то $A = \vec{0}$ (нулевой вектор)
