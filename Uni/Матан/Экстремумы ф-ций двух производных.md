# Достаточное условие экстремума:

Пусть z = f(x,y) имеет в точке (x0, y0) частные производные, равные нулю:
* z'x (x0, y0) = 0;
* x'y (x0, y0) = 0;

Найдем значения вторых производных в (x0, y0)
* A = z''xy (x0, y0)
* B = x''yy (x0, y0)
* C = x''xx (x0, y0)

И вычисляем
$\Delta = A*C - B^2$

Если $\Delta > 0$, то экстремум в точке существует:
	При A < 0, (x0, y0) - т. максимума
	При A > 0, (x0, y0) - т. минимума

Если $\Delta < 0$, нет экстремума в точке

Если $\Delta = 0$, нужно руками смотреть, что там происходит (крутяк)
