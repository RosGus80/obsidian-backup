#Пределы


Простейшие пределы вычисляются путем подставления значения, к которому стремится независимая переменная, в функцию.

$\lim_{ x \to \ 1 }\left(\frac{x^2+3x}{2x} \right) = \frac{1+3}{2} = 2$
$\lim_{ x \to \infty } \left( \frac{1}{x} \right) = 0$
и т.д.

Для остальных пределов применяются соответствующие техники вычисления:

##### Пределы частного - по коэффициенту при старшей степени

Пределы, приводящие к неопределенностям при обычном подставлениям, могут выглядеть следующим образом:
$\lim_{ x \to \infty }\left( \frac{x^2+3x}{3x^2-2x+1} \right)$
При подставлении бесконечности в функцию мы не получаем конкретного числа: $...= \infty$

В таком случае мы можем разделить числитель и знаменатель на независимую переменную с наибольшим коэффициентом:
$\lim_{ x \to \infty }\left( \frac{x^2+3x}{3x^2-2x+1} \right) = \lim_{ x \to \infty }\left( \frac{\frac{x^2}{x^2}+\frac{3x}{x^2}}{\frac{3x^2}{x^2}-\frac{2x}{x^2}+\frac{1}{x^2}} \right)$ 
Поскольку x стремится к бесконечности, там, где x не сокращается обычным образом, дробь стремится к нулю:
$\lim_{ x \to \infty }\left( \frac{x^2+3x}{3x^2-2x+1} \right) = \lim_{ x \to \infty }\left( \frac{\frac{x^2}{x^2}+\frac{3x}{x^2}}{\frac{3x^2}{x^2}-\frac{2x}{x^2}+\frac{1}{x^2}} \right) = \lim_{ x \to \infty }\left( \frac{1+0}{3-0+0} \right) = \frac{1}{3}$
Таким образом, при x стремящимся к бесконечности, пределы функций деления определяются по коэффициентам при старшей степени независимой переменной. Если в старшая степень числителя (знаменателя) старше, чем старшая степень знаменателя (числителя), предел равен бесконечности (нулю):
$\lim_{ x \to \infty }\left( \frac{x^3+2x}{x^2+50x} \right) = \infty$

##### При неопределенности вида $\frac{0}{0}$ - разложить числитель и знаменатель на множители

Числители и знаменатели можно раскладывать своей техникой разложения. Например, [[Разложение квадратного трехчлена по нулям]].

После разложения, в экзаменационных задачах, предел обычно должен сокращаться. Например:

$\lim_{ x \to -1 }\left(\frac{2x^2-3x-5}{x+1} \right) = \frac{0}{0}$
$\lim_{ x \to -1 }\left(\frac{2x^2-3x-5}{x+1} \right) = \lim_{ x \to -1 }\left(\frac{2x-5}{1} \right) = -7$  

##### При неопределенности вида $\frac{0}{0}$ и наличии разности корней - домножение на сопряженное выражение

Сопряженное выражение - такое, которое, при добавлении к разности корней, сделает из выражения формулу разности квадратов.
Пример:

$\lim_{ x \to 3 }\left( \frac{\sqrt{x+6} - \sqrt{10x-21}}{5x-15} \right)$
При подставлении x=3 получаем $\frac{0}{0}$.
Сопряженным выражением для числителя будет $(\sqrt{x+6} + \sqrt{10x-21})$, потому что $(\sqrt{x+6} - \sqrt{10x-21})(\sqrt{x+6} + \sqrt{10x-21}) = (\sqrt{x+6})^2 - (\sqrt{10x-21})^2$

В числителе все соберется в квадрат, а в знаменателе домноженную часть, вероятно, можно будет вынести за лимит:

$\lim_{ x \to 3 }\left( \frac{(\sqrt{x+6})^2 - (\sqrt{10x-21})^2}{(5x-15)((\sqrt{x+6} + \sqrt{10x-21}))} \right) = \frac{-9*3+27}{(5*3-15)(\sqrt{ 9 } + \sqrt{ 9 })})$. Можно справедливо заметить, что неопределенность $\frac{0}{0}$ не исчезла, однако мы можем вынести результат домножения знаменателя ($\frac{1}{6}$) за лимит:
$\frac{1}{6} * \lim_{ x \to 3 }\left( \frac{-9x+27}{5x-15} \right)$. Далее применяем метод [[Вычисление пределов#При неопределенности вида $ frac{0}{0}$ - разложить числитель и знаменатель на множители|разложения на множители]]:
$\frac{1}{6} * \lim_{ x \to 3 }\left( \frac{-9(x-3)}{5(x-3)} \right) = \frac{1}{6} * \lim_{ x \to 3 }\left( -\frac{9}{5} \right) = -\frac{9}{30} = -\frac{3}{10} = -0.3$

##### Замечательные пределы

###### Первый замечательный предел 
имеет вид:
${\lim_{ x \to 0 } \frac{(\sin x)}{x} }= 1$
Так же, в задачах может встретиться вид $\lim_{ x \to 0 }\left( \frac{x}{\sin x} \right)=1$. Однако собственноручно (по какой-то причине) переставлять их нельзя.
Аргументом необязательно должна быть свободная переменная. Аргументом может служить и функция. Главное, чтобы в данном пределе она стремилась к нулю. Например:
$\lim_{ x \to 0 }\left(\frac{\sin_{5x}}{5x} \right)$; $\lim_{ x \to \infty } \left( \frac{\sin\left( \frac{1}{x} \right)}{\left( \frac{1}{x} \right)} \right)$ ; 

Если мы видим синус в пределе, стремящемся к нулю, мы должны придумать, как запихнуть этот предел в форму первого замечательного.
Так,
$\lim_{ x \to 0 }\left( \frac{\sin{7x}}{3x} \right)= \lim_{ x \to 0 }\left( \frac{\sin{7x}}{3*\frac{1}{7}*7x} \right) = \lim_{ x \to 0 }\left( 1*\frac{1}{3*\frac{1}{7}} \right)= \frac{7}{3}$
Еще один пример:
$\lim_{ x \to 0 }\left( \frac{5x^2}{\sin^2\left( \frac{x}{2} \right)} \right) \left( =\frac{0}{0} \right) = \lim_{ x \to 0 }\left( \frac{5*2*2*\frac{x}{2}*\frac{x}{2}}{\sin\left( \frac{x}{2} \right)*\sin\left( \frac{x}{2} \right)} \right)) = \lim_{ x \to 0 }(20*1*1) = 20$

###### Второй замечательный предел
Имеет вид:
$\lim_{ x \to \infty }\left( \left( 1+\frac{1}{x} \right)^x \right) = e$
Причем, опять же, на месте х может быть не просто свободная переменная, но функция. Главное - чтобы в данном пределе она стремилась к бесконечности:
$\lim_{ x \to \infty }\left( \left( 1+\frac{1}{4x} \right)^{4x} \right) = e$

Обычно подгон предела идет не из выражения в скобках, но путем наслаивания новых степеней на ф-цию. Общия принцип такой: убрать изначальную степень куда подальше и возвести предел в степень x и степень $\frac{1}{x}$, чтобы не поменять выражение.
Например:
$\lim_{ x \to \infty }\left( \left( 1+\frac{1}{5x} \right)^{2x} \right) = \lim_{ x \to \infty }\left( \left((( 1 + \frac{1}{5x} \right)^{5x})^{\frac{1}{5x}})^{2x} \right)$. Получается довольно громоздкая запись, но суть ясна. И следующим же шагом это большое выражение схлопывается до:
$e^{\lim_{ x \to \infty }(\frac{1}{5x} * 2x)}$. Причем предел переходит на степени е (не знаю, почему). В таком случае надо просто дорешать предел в степени:
$e^{\frac{4}{10}}$ - решение [[Вычисление пределов#Пределы частного - по коэффициенту при старшей степени|по коэффициенту при старшей степени]].
