#Производные 

1) C' = 0, C = const
2) $(x^n)' = n*x^{n-1}$
3) $(e^x)' = e^x$
4) $(log_{a}{x})' = \frac{1}{x*ln{a}}$
5) $(\ln{x})' = \frac{1}{x}$
6) $(\sin x)' = \cos x$
7) $(\cos x)' = -\sin x$
8) $(\sqrt{ x })' = \frac{1}{2*\sqrt{ x }}$
9) $(\tan x)' = \frac{1}{(\cos x)^2*x}$
10) $(\cot x)' = - \frac{1}{(\sin x)^2}$
11) $(\arcsin x)' = \frac{1}{\sqrt{ 1-x^2 }}$
12) $(\arccos x)' = - \frac{1}{\sqrt{ 1-x^2 }}$
