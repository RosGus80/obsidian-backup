1) F(x) - первообразная для f(x), если F'(x) = f(x)
2) $\int f(x)dx = F(x)+C$ - обобщенный интеграл

Неопределенный интеграл решается:
1) Интегрирование ("в лоб")
2) Заменой переменной
3) Интегрирование по частям

### Интегрирование "в лоб"

$\int1(*dx) = x+C$
$\int x^ndx = \frac{x^{n+1}}{n+1}+C$
$\int xdx = \frac{x^2}{2}+C$
$\int x^2dx =\frac{x^3}{3}+C$
$\int \sqrt{ x }dx = \frac{2x^{3/2}}{3} +C$
$\int \frac{dx}{x} = \ln|x| +C$
$\int \frac{dx}{x} = 2\sqrt{ x } + C$
