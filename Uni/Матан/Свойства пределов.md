Пусть $\lim_{ x \to x_{0} }f(x) = A$ ; $\lim_{ x \to x_{0} } = B$

1) Если f(x) $\leq$ g(x) для всех х, то A $\leq$ B
2) Если $f(x) \leq h(x) \leq g(x)$ для всех х, и A = B, то $\lim_{ x \to x_{0} } = A$
3) $\lim_{ x \to x_{0} }(f(x) \pm g(x)) = A \pm B$
4) $\lim_{ x \to x_{0} }(C*f(x)) = C * A$ (C e R)
5) $\lim_{ x \to x_{0} }(f(x) * g(x)) = A*B$
6) $\lim_{ x \to x_{0} }(\frac{f(x)}{g(x)} = \frac{A}{B}$ (если B $\ne$ 0)
