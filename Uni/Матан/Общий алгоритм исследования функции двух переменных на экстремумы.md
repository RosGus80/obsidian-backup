#Производные #ФДвухПеременных 

1) Найти [[Частные производные функций двух переменных]] первого порядка
2) Определить критические точки функции, решая систему
	z'x = 0
	z'y = 0
3) Найти [[Производные второго порядка]] в найденных точках-решениях СЛУ
4) Для каждой критической точки найти:
	* $A = z''xy (x0, y0)$
	* $B = x''yy (x0, y0)$
	* $C = x''xx (x0, y0)$
	* $delta = A*C-B^2$ 
5) На основании вычислений сделать вывод об экстремумах функции двух переменных:
	* Если delta > 0, то экстремум в точке существует:
		При A < 0, (x0, y0) - т. максимума
		При A > 0, (x0, y0) - т. минимума
	* Если delta < 0, нет экстремума в точке
	* Если delta = 0, нужно руками смотреть, что там происходит (крутяк)
