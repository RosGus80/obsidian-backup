Асимптоты могут иметь место в точках, где функция не определна. Чтобы проверить, является ли соответствующая точка асимптотой, надо вычислить соответствующие пределы (см. [[Вычисление пределов]]):
1) Вертикальная асимптота: Если хотя бы один из односторонних пределов функции в точке равен $\infty$
	Пример:
	$\frac{1}{x-2}$
	Ф-ция не определена при x=2. Считаем односторонние пределы при х -> 2:
	$\lim_{ x \to 2+0 }\left( \frac{1}{x-2} \right) = \frac{1}{+0+2-2} = \frac{1}{+0} = \infty$. Следовательно, х = 2 - вертикальная асимптота нашей функции.
2) Невертикальная асимптота: Если существует такая функция y = kx + b, что:
	$k = \lim_{ n \to \infty }\frac{f(x)}{x}; b = \lim_{ x \to \infty }f(x)-kx$
