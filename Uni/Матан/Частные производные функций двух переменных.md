#Производные 

Частные производные функций двух переменных дифференцируются по одной из независимых переменных, причем остальные независимые переменные при дифференцировании считаются константами (для них применяется правило С' = 0) см. [[Таблица производных]].

Так, при z = f(x, y) = 2x + 3y:

z'x = (2x)'x + (3y)'x = 2 + 0 = 2
z'y = (2x)'y + (3y)'y = 0 + 3 = 3
