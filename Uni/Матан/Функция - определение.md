
**Функция** — это правило, которое устанавливает соответствие между элементами одного множества (область определения) и элементами другого множества (множество значений). Формально, функция  f  из множества  X  в множество  Y  обозначается как  f: X → Y . Для каждого элемента  x ∈ X  существует единственный элемент  y ∈ Y , такой что  f(x) = y .

* **Область определения** функции  f(x)  — это множество всех возможных значений переменной  x, для которых функция определена.

* **Множество значений** — это множество всех значений, которые может принимать функция  f(x) , то есть  Y = { f(x) | x ∈ Df } , где  Df  — область определения функции.
