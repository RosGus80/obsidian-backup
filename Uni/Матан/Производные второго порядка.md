#Производные 
## Функций одной переменной

Производные второго порядка находятся путем дифференцирования производной первого порядка (см. [[Таблица производных]])
	   f(x)'' = (f(x)')'
	   В общем виде:
	   f(x)'*n = (f(x)'*n-1)'

## Функций двух переменных

Производные второго порядка для функций двух переменных находятся двумя равносильными способами (см. [[Частные производные функций двух переменных]]):

Для z = f(x, y)

1) Дифференцированием (см. [[Таблица производных]]):
		$z''xy = (z'x)'y$
		$z''xx = (z'x)'x$ и т.д.
1) Умножением:
		$z''xy = z'x * z'y$ и т.д.

Пример:

$z = f(x, y) = y^3-x^2 + xy -52$

$z'x = 0 - 2x + y - 0 = y - 2x$
$z'y = 3y^2 - 0 + x - 0 = 3y^2 + x$

Поскольку $z''xy = z'x * z'y = z'y * z'x$ (см. способ дифференцирования умножением выше), $z''xy = z''yx$ при любых условиях. 

$z''xy = z''yx = (z'x)'y = (y - 2x)'y = 1$
$z''xx = (z'x)'x = (y - 2x)'x = -2$
$z''yy = (z'y)'y = (3y^2+x)'y = 6y$
